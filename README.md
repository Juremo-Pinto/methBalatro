# CPG

Um projeto feito pelo trio Rethi, 11pog e Juremo durante o CPG (Coding Pizza Glory), um evento de 3 dias de duração estilo game jam com o objetivo de fazer um jogo com o tema "matemática", infelizmente o projeto não foi terminado a tempo resultando na nossa derrota.

O principal motivo da derrota foi a privação de sono e nutrição que o proprio grupo se subjulgou, causando em um burnout simultaneo no ultimo dia, nenhum integrante conseguia produzir ao final do evento e o tempo acabou.

Não ganhamos o evento mas ganhamos experiencia.
